# Polyglot Calculator 

Using as many programming languages as we can to make a calculator!

This project was made for hackaton, by our great team 1. 

## Language Map
- [C](c)
- [Python](python)
- [Assembly](c/src/main.c) (in [`./c/src/main.c`](c/src/main.c), `op_add`)
- [Java](java/Main.java) (in [`./c/src/main.c`](c/src/main.c), `op_mul`)
- [D](c/src/op_div.d)
- [C++](c/src/op_matrix.cpp) (matrices via [Uranium](https://github.com/neoapps-dev/Uranium))
- [Lua](lua)
- [Kotlin](kotlin/KotlinMain.kt)
- [Groovy](groovy/GroovyMain.groovy) (`cos`)
- [Scala](scala/ScalaMain.scala) (`tan`)
- [HTML/CSS/JS](web) mostly by K
